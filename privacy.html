Privacy Notice

Last updated: 22 November 2026

PeakCut’s Android AI Office creates original Android help videos and uploads them to the owner’s YouTube channel. This notice describes the information the workflow uses.

Account access and credentials

The channel owner authorizes Google access with the YouTube upload permission. The workflow uses it to upload videos and their titles, descriptions, and tags to that channel. The owner can revoke access from their Google Account’s connected-app settings.

The OAuth client ID, OAuth client secret, YouTube refresh token, and Gemini API key are stored as encrypted repository secrets in the owner’s private GitHub repository. GitHub Actions reads them when a workflow runs. They are not included in scripts or videos.

Content and services

The workflow reads public Android and Google support pages. Relevant public text and proposed scripts are sent to Google’s Gemini API to draft and fact-check video scripts. Completed videos and metadata are sent to YouTube for upload. GitHub hosts the private source repository and topic history; GitHub Actions temporarily processes each run.

Retention and sharing

The private repository retains topic history, titles, narration, and YouTube video IDs to help avoid repeating topics. YouTube stores uploaded videos according to the selected visibility setting and the channel owner’s choices. The workflow does not sell personal information or use advertising trackers.

The workflow is not designed to collect information from video viewers. The owner can remove repository secrets in GitHub settings, revoke Google access in their Google Account, and change or delete videos in YouTube Studio.

Changes and contact

This notice may change when the workflow or services change. For privacy questions, use the support contact shown on the PeakCut Google sign-in and consent screen.
